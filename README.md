# Naive RAG Chatbot

A beginner RAG (Retrieval-Augmented Generation) chatbot built while learning how RAG systems work.

This project is intended as a learning project. 

## What I Learned

* Document loading and text chunking
* Embeddings
* Vector databases
* Similarity search
* Retrieval-Augmented Generation
* Working with LLMs

## Technologies

* Python
* LangChain
* Gemini (LLM)
